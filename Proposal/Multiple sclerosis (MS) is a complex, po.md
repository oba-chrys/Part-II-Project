Multiple sclerosis (MS) is a complex, polygenic autoimmune disorder wherein the immune system attacks myelin, the protective cover of nerve cells (axons) in the Central Nervous System (CNS)\parencite{boutitah-benyaichMultipleSclerosisMolecular2025}. Although damage can be partially  mitigated by the re-routing of messages using undamaged nerve cells (plasticity), the damage eventually becomes too extensive to compensate for, resulting in progressive neurodegeneration. A multitude of clinical tests are currently used in diagnosing MS, and recently, AI has shown promise in providing more personalised treatments, disease monitoring and the identification of biomarkers that may aid in disease prognosis and diagnosis\parencite{aminArtificialIntelligenceMultiple2024}, the lattermost being the focus of this project.

Gene expression is the process outlined by the central dogma of molecular biology: DNA is transcribed into RNA, and RNA is translated into functional products. The measure of how much a gene is expressed at a given time is referred to as its gene expression level, and the analysis of differential expression levels when comparing healthy people and diagnosed patients can aid in the development of disease signatures based on changes in gene activity. 

Transcriptomics is a sub-branch of omics focused on the  study and analysis of the transcriptome, the collection of all RNA transcripts present in a sample at a given time. Epigenomics is the study of the chemical compounds that control the behaviour of the genome. Studying the epigenome may in future be used to detect harmful molecular changes before physical symptoms appear, acting as an early warning signal\cite{alarconMetabolicEarlyWarning2025,lesterEmergenceDevelopmentalBehavioral2022}. 

Single-cell RNA-sequencing as described in \textcite{lueckenCurrentBestPractices2019} is a technique used to produce raw RNA sequence reads which can be used to produce gene expression matrices, where rows represent genes and each column represents a single cell, with a matrix cell representing how active that particular gene is. Analogously, scATAC-seq analyse open chromatin (which allow for gene expression) to produce peak count matrices where rows represent peaks and columns represent individual cells, with the individual matrix cells representing the number of sequence reads. Advanced, high-throughput technologies for studying gene expression, such as single-cell RNA sequencing (scRNA-seq) and single-nucleus RNA sequencing (snRNA-seq), allow gene expression to be measured at the level of individual cells or nuclei, enabling the heterogeneity of cell populations to be explored.  Studies have utilised snRNA-seq data in clustering distinct  MS sub-groups\parencite{macnairSingleNucleiRNAseq2022} providing a basis for use in future individualised treatment.

Given that the complexity of biological networks in higher organisms  primarily arises from dynamic gene interactions as opposed to the size of the genome (C-value paradox), analysing gene dynamics offers a more informative framework for understanding biological systems. Gene-gene co-expression networks (GGCNs) are typically presented as undirected graphs where nodes are genes and the presence of edges depends on co-expression values calculated from gene expression data\parencite{vandamGeneCoexpressionAnalysis2017}. These networks can be used to identify the functional status of genes from a systemic perspective, which can in turn inform the discovery of gene-disease associations through guilt-by-association analyses. Several frameworks have been used to infer GGCNs from snRNA-seq data, including the WGCNA framework, and its extension hdWGCNA, which will be used to build the multi-layer co-expression network for this project.  

Graph neural networks (GNNs) have commonly been used for tasks like graph classification, node classification and link prediction\parencite{sewellGNNsNetworkClassification2025}. Given a graph $G(V,E)$  as input in the form of a node feature matrix ($H:  \mathbb{R}^{N \times F}$), GNNs produce new node embeddings that capture the node features, and the learnt embeddings can be used for graph classification. Graph Attention Networks (GATs) introduce a masked attention mechanism which works by constraining the nodes taken into account in computing the updated features for a node to its neighbourhood\parencite{velickovicGraphAttentionNetworks2017} - previous works have successfully applied these networks to disease prediction\parencite{ravindraDiseaseStatePrediction2020}. To reflect the cell-type specific gene co-expression,a multi-layer graph, known as a multiplex graphs will be used, requiring the use of a multiplex GAT (mGAT).

In this project, snRNA-seq data from diagnosed MS patients and healthy control will be transformed into multi-layer co-expression networks using the hdWGCNA framework. These graphs will be used as input to an mGAT whose initial downstream task will be binary MS classification. The contributions of the project are: 
\begin{itemize}
\item The leveraging of the hdWGCNA framework to construct the multiplex co-expression networks

\item The design of an mGAT architecture that uses the GGCNs as input for downstream binary classification 
\item The performance comparison of the proposed mGAT architecture against the baseline GAT model. 
\end{itemize}

\section{Substance and Structure}
\subsection{Datasets}
The datasets to be used for this project are items \cite{zotero-item-47,elkjaerDatasetArticleSingleCell2024,macnairSingleNucleiRNAseq2023,zotero-item-33} and each include a subset of transcriptomic (snRNA-seq) and epigenomic (snATAC-seq) data.
\subsection{Data Processing and Libraries}
hdWGCNA is an extension of the WGCNA framework which allowed bulk RNA-seq data to be transformed into gene co-expression networks adapted to handle higher dimensional single-cell datasets. Given the output of cell-type specific GGCNs, a multiplex graph can be constructed from the outputs. A multiplex graph is informally defined as a graph where node are split into layers and both interlayer and intralayer edges may be present. 

The choice of a graph architecture reflecting the heterogeneity of cells in samples is due to the differential expression levels of different cell types, however, whether this affects classification will be tested by the inclusion of a traditional GAT. Whilst initially written in R, a Python re-implementation, py-hdWGCNA, has been written that is numerically faithful to the original package, and will be used. 

The tensor data structure and associated operations from the PyTorch library will be used to write the linear layers and graph attention layers as required for the GAT, mGAT and MLP models rather than using the prebuilt library functions. The sci-kit library will be used to split the processed dataset into training, validation and testing datasets.
